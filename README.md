# 📔 Joury (Journaling App) -- UI/UX Design Prototype

A journaling web application developed as part of a university Software Engineering course.  
This project mainly focuses on **UI/UX design and frontend layout**, with some features currently implemented as UI prototypes (dummy interactions).

---

## 🎯 Project Overview

This application is designed to simulate a simple digital journaling experience where users can:
- View a journaling interface
- Interact with UI components (buttons, forms, navigation)
- Experience the overall layout and design flow

⚠️ Note: Some features are not fully functional and are implemented as UI prototypes.

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript (basic interactivity)
